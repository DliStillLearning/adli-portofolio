PROJECT 05 · WEB APPLICATION

LSP-ERAPORT.

Aplikasi web untuk pengelolaan nilai rapor dengan alur pengguna dan akses yang disesuaikan berdasarkan peran.

KategoriWeb applicationTeknologiLaravel · PHP · Blade · Database relasionalStatusLatihan dan pengembangan

GAMBARAN

Data nilai yang
terstruktur.

Tujuan

Mempelajari alur aplikasi rapor yang melibatkan data siswa, wali kelas, kelas, dan nilai melalui framework Laravel.

Area teknis yang dipelajari

  • Route dan controller.
  • Blade template dan form create/update.
  • Validasi request dan session role.
  • Relasi Eloquent dan penelusuran error.

Hal yang dipelajari

Memahami bahwa relasi model, bentuk data yang dikembalikan, validasi, dan metode HTTP harus selaras agar proses pembaruan data berjalan benar.

Halaman ini menekankan pembelajaran teknis; status fitur perlu diperbarui setelah diuji.
