PROJECT 02 · DESKTOP APPLICATION

Roomify.

Konsep aplikasi desktop untuk membantu pengelolaan reservasi hotel, kamar, pelanggan, dan transaksi.

KategoriDesktop applicationTeknologiC# · Windows Forms · SQL Server · Guna UI2StatusDalam pengembangan

GAMBARAN

Operasional hotel
dalam satu aplikasi.

Tujuan

Membuat aplikasi desktop untuk memusatkan pengelolaan data kamar, pelanggan, reservasi, serta transaksi hotel.

Ruang lingkup

  • Peran pengguna: admin, manajer, dan resepsionis.
  • Data kamar dan tipe kamar.
  • Transaksi reservasi dan status pemesanan.
  • Pengelolaan fasilitas tambahan.

Hal yang dipelajari

Pemodelan data relasional, operasi CRUD, validasi formulir, dan hubungan antara antarmuka desktop dengan SQL Server.

Detail fitur akan diperbarui sesuai implementasi akhir aplikasi.
